# Security

Forge is a local inspection tool, not a sandbox for hostile repositories. Its worker protocol
is not a network API. Reports may contain source code, local paths, and thread details.

If you find a vulnerability, email **muhammadtalhabinkhalid@gmail.com** with a minimal
synthetic reproduction and affected version. Do not include private investigation data or
publish an exploit against a third party. Response times are not guaranteed.

Preview releases have limited compatibility guarantees. Use the latest preview and keep
backups of important workspaces.
